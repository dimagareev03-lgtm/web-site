# Кастадент — сайт стоматологии

Одностраничный сайт клиники «Кастадент» (Краснодар, ул. Архитектора Ишунина, 3).
Вся вёрстка, стили и скрипты лежат в одном файле `index.html` — сборка не нужна,
достаточно открыть файл в браузере или положить на любой хостинг.

## Что внутри

- Первый экран с фотографией на всю высоту
- Услуги, акции, фотографии клиники, команда врачей, карта, форма записи
- Окна поверх страницы: «О клинике», «Врачи», «Лицензии и документы», «Услуги и цены», «Прайс», «Контакты» и страницы акций
- Бежевая палитра со светлой и тёмной темой (следует настройке системы)
- Адаптив под телефон: бургер-меню, окна на весь экран

## Публикация

Репозиторий готов к GitHub Pages: Settings → Pages → Source: `main`, папка `/ (root)`.
Сайт откроется по адресу вида `https://<логин>.github.io/web-site/`.

## Что стоит доделать перед запуском

- Формы записи и обратной связи сейчас открывают почтовый клиент через `mailto:`.
  Для рабочего сайта нужна настоящая отправка — на почту клиники или в CRM.
- Сертификаты в разделе «Лицензии и документы» взяты из шаблона. Их нужно
  заменить на документы клиники.
